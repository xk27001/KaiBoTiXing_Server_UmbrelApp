## 产品概述

对抖音主播开播监控软件的界面交互进行三项优化：调整 Tab 顺序、优化开播状态展示、实现最小化到系统托盘。

## 核心功能

1. **Tab 顺序调整**：将「监控状态」Tab 移至最前面，Tab 顺序变为「监控状态 → 主播管理 → 日志查看」，让用户打开软件即看到监控状态。

2. **开播状态列优化**：在监控状态表中，将「开播状态」列移至第一列；开播时该列显示「开播中」并用红色字体醒目提示，未开播显示「未开播」，异常显示「未知」（灰色/橙色）。

3. **最小化到系统托盘**：

- 点击窗口关闭按钮（X）时，不退出程序，而是隐藏窗口并驻留系统托盘。
- 软件开机自启动后，自动最小化到系统托盘（不弹出主窗口）。
- 系统托盘图标支持：双击恢复主窗口、右键菜单「显示主窗口」和「退出」。
- 「退出」菜单项才真正释放资源并退出程序。

## 技术栈

- Java 25 + JavaFX 23.0.2（沿用现有）
- java.awt.SystemTray + TrayIcon + PopupMenu（系统托盘，Windows 原生支持）
- BufferedImage 动态绘制托盘图标（无需新增资源文件）

## 实现方案

### 1. Tab 顺序调整

文件：`src/main/java/com/kaibotixing/ui/MainController.java` 的 `getRoot()` 方法。

将 `tabPane.getTabs().addAll(...)` 中 Tab 的创建顺序从「主播管理、监控状态、日志查看」改为「监控状态、主播管理、日志查看」。

### 2. 开播状态列优化

文件：`MainController.java` 的 `buildStatusTab()` 方法。

- 将 `colStatus`（开播状态）移到 `statusTable.getColumns().addAll(...)` 的第一个参数位置。
- 将状态列从 `PropertyValueFactory` 改为 `setCellFactory` 自定义渲染：
- `LiveStatus.LIVE` → 文本「开播中」，字体颜色红色（Color.RED 或 #e74c3c），加粗。
- `LiveStatus.OFFLINE` → 文本「未开播」，默认黑色。
- `LiveStatus.UNKNOWN` → 文本「未知」，灰色或橙色（#ff9800）。

注意：`LiveStatus.getLabel()` 中 LIVE 的 label 是「直播中」，为满足用户「开播中」的要求，在 cellFactory 中做映射，不修改 LiveStatus 枚举本身（避免影响主播管理表的「最新状态」列显示）。

### 3. 最小化到系统托盘

文件：`src/main/java/com/kaibotixing/MainApplication.java` 的 `start()` 方法。

实现步骤：

1. 用 `BufferedImage`（16x16，TYPE_INT_ARGB）动态绘制一个简单图标（如红色圆形），作为 TrayIcon 图标。
2. 检查 `SystemTray.isSupported()`（Windows 为 true），创建 `TrayIcon` + `PopupMenu`。
3. `PopupMenu` 菜单项：

- 「显示主窗口」：`primaryStage.show()` + `primaryStage.toFront()`。
- 「退出」：`controller.shutdown()` + `SystemTray.remove(trayIcon)` + `Platform.exit()`。

4. 设置 `trayIcon` 双击事件 → 显示主窗口。
5. 拦截窗口关闭：`primaryStage.setOnCloseRequest(e -> { e.consume(); primaryStage.hide(); })`，实现点击 X 最小化到托盘。
6. autoStart 场景：启动后不显示主窗口，直接最小化到托盘（`primaryStage.hide()`，可选托盘气泡提示「已最小化到托盘」）。
7. 将 `controller` 提升为字段或局部变量供托盘「退出」菜单调用 `shutdown()`。

### 线程安全

- `SystemTray`、`TrayIcon` 操作在 `start()` 中直接调用（`start()` 运行在 JavaFX Application Thread，AWT 托盘操作是线程安全的，无需额外切换）。
- 托盘菜单事件回调需用 `Platform.runLater()` 包裹，确保回到 FX 线程操作 Stage。

## 实现细节

- 托盘图标：`BufferedImage` 绘制 16x16 红色圆形（或色块），避免新增资源文件，同时保持 exe 打包无额外依赖。
- 列宽持久化：`ColumnWidthStore` 的 key 基于列 index，状态列移到第一列会导致历史保存宽度错位。本次保持 index 方式（改动范围小），用户重新手动调整列宽后会自动重新保存覆盖。
- 真正退出时，`shutdown()` 会停止 refreshTimer 和 scheduler，`MainApplication.stop()` 中 `DataSourceManager.close()` 关闭连接池。
